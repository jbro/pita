# US-4: Multi-Session Navigation and Creation

The user is working in a session and wants to start or switch to a parallel session.

- Ctrl+Up opens a mission-control overlay showing all active sessions in the current project
- Arrow keys navigate between session previews and a "+" button
- Enter on a session switches to it (makes it the active/foreground session)
- Enter on "+" creates a new session
- Esc closes the overlay and returns to the current session
- Ctrl+N is a shortcut to create a new session and immediately make it active
