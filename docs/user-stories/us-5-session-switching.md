# US-5: Session Switching

The user wants to switch between active sessions quickly.

- Ctrl+Left and Ctrl+Right cycle through active sessions in order
- Ctrl+Up opens mission control (see US-4) for a visual overview
- Each session in mission control shows its idle/busy state
- Filtering in mission control may be supported (e.g. show only busy/idle sessions)
- Arrow keys select a session in mission control, Enter switches to it
