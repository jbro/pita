# User Stories

Features are specified as user stories before implementation. One file per story. Stories can be implemented in any order.

## Conventions

- **Lazy session creation:** a session is persisted only after the first prompt.
- **Archive, never delete:** closing a session archives it. Cleaning archived sessions is a separate concern (future story).
